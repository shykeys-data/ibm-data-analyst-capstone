# IBM Data Analyst Capstone Project

Analysis of the 2024 Stack Overflow Developer Survey (65,437 respondents after cleaning) for the IBM Data Analyst Professional Certificate.

## Dashboard

Developer_Survey_Dashboard.pdf is the IBM Cognos Analytics dashboard with 3 tabs: Current Technology Usage, Future Technology Trend and Demographics.

## Presentation

Data_Analyst_Capstone_2026_Filled.pptx contains the final findings presentation.

## Key findings

JavaScript leads job postings (2,241), followed by Java (1,209) and Python (1,165).

PostgreSQL is the most-used database and grows next year (994 to 1,265).

Median yearly salary is $65K vs a mean of $86K because of extreme outliers.

Most respondents are aged 25-34 (41.3%) and hold a Bachelor's degree.
